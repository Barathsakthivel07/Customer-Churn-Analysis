# Customer Churn Analysis | Python, Pandas, Matplotlib

An end-to-end beginner-friendly exploratory data analysis portfolio project investigating which groups of telecom customers are more likely to leave.

## Business questions
- What percentage of customers churn?
- How does churn differ by contract type and payment method?
- How are tenure and support-ticket counts associated with churn?
- Are monthly charges different for churned vs retained customers?

## Dataset
`data/customer_churn.csv` is a **synthetic, reproducibly generated practice dataset** (1,000 fictional customers). It is not a real telecom company dataset. Findings are illustrations only and should not be generalized to real businesses.

## Run on Windows (VS Code terminal / PowerShell)
```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe churn_analysis.py
```
If `py` is unavailable, use `python -m venv .venv` instead.

## Methods
Use Pandas to validate data, remove duplicate IDs, handle missing values, segment customers, and compute churn percentages. Use Matplotlib for five static PNG charts. Charts and CSV are regenerated by running the script.

## Interpretation
Focus on descriptive **associations**, not proof of causation. Compare the segments in the generated `churn_summary.csv` before discussing business recommendations. Potential experiments include better onboarding for month-to-month subscribers and improved support resolution, but results should be validated on real data.

## Business Insights

Analysis of 1,000 synthetic telecom customers identified:

- Overall customer churn rate: 28.9%
- Month-to-month contract churn: 37.5%
- First-year customer churn: 40.0%
- Churn among customers with 3+ support tickets: 43.3%

### Recommendations

1. Improve customer onboarding.
2. Prioritize customers with repeated support issues.
3. Test long-term contract incentives.
4. Investigate billing and payment difficulties.
